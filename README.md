# CASESIM — симулятор кейсов CS2

Сайт в стиле кейс-сайтов CS2. Работает только на **виртуальной валюте**: нет пополнений, выводов, Steam-авторизации и реальных денег. Прогресс хранится в `localStorage` браузера.

## Возможности

- **Свои кейсы** — 45 авторских кейсов в 9 сериях (Стихии, Мифы, Космос, Улицы, Неон, Статус, Оружие, Премиум, Особые), в каждом 30–50 скинов. Коробки кейсов нарисованы кодом в SVG (`js/art/`): 6 стилей и 40 эмблем, без чужих картинок. Плюс 42 копии кейсов CS2 и 3 бесплатных кейса по уровням.
- **Шансы как у конкурентов** — у каждого предмета строки «износ × StatTrak» со своей ценой и билетами из 100 000; шанс ∝ цена^−1,2, RTP 88% (ножевые 90%), как у Hellcase и Skin.club. На странице кейса — шанс окупа, таблица билетов, RTP.
- **Provably fair** по схеме Stake (HMAC-SHA256): заранее показанный хэш server seed, свой client seed, nonce, проверка любого результата на странице «Честная игра».
- **Апгрейд** — шанс = ставка / цель × 0,9 (как Key-Drop и Cases.gg), 1–75%, режимы «Меньше/Больше», стрелка останавливается ровно на выпавшем числе.
- **Контракты** — лёгкий (x0,8–1,2), средний (x0,2–5) и сложный (x0,05–10), как у Hellcase.
- **Батлы** — 1v1, 1v1v1, 1v1v1v1, 2v2, 3v3; режимы Классика, Crazy, Terminal, Jackpot, Group; боты помечены.
- **Бонусы** — колесо раз в сутки с множителем уровня, бесплатные кейсы с 2, 10 и 20 уровня, кран и промокоды (`WELCOME`, `CASESIM`, `FREE`, `KNIFE`).
- **Результат фиксируется до анимации** — перезагрузка страницы посреди открытия, апгрейда или батла ничего не меняет.
- Анимации открытия, частицы и вспышки по редкости, звуки, адаптивная вёрстка.

## Вход через Steam

Играть можно только после входа: без него сайт открыт для просмотра. Кнопка «Войти через Steam» отправляет на официальный сайт **steamcommunity.com** (OpenID 2.0). Пароль вводится только там, сайт получает лишь SteamID. Аккаунт создаётся при первом входе (стартовые 500 монет), у каждого аккаунта своё сохранение.

Есть два режима:

| | Без сервера (по умолчанию) | С сервером (Cloudflare Worker) |
|---|---|---|
| Настройка | ничего не нужно | ~10 минут, бесплатно |
| SteamID | берётся из ответа без проверки подписи | проверяется у Steam |
| Ник и аватар Steam | ник выбирается при первом входе | да: ставятся при входе и обновляются при каждом заходе на сайт (с ключом API или из открытого профиля) |
| Сохранение между устройствами | нет | да (KV) |

Режим без сервера работает только когда сайт открыт по `http(s)://` (GitHub Pages, `python3 -m http.server`), но не как файл.

### Как включить сервер

1. **Ключ Steam Web API**: https://steamcommunity.com/dev/apikey. Domain Name: адрес сайта, например `pavl1k999.github.io`. Ключ выдают только аккаунтам без ограничений (с покупками в Steam от $5).
2. **Worker**: зарегистрируйтесь на https://dash.cloudflare.com → *Workers & Pages* → *Create* → *Create Worker*, имя `casesim-auth` → *Deploy* → *Edit code*. Замените код содержимым файла `worker/index.js` → *Deploy*.
3. **Переменные** (Worker → *Settings* → *Variables and Secrets*):
   - `ALLOWED_ORIGINS`, тип *Text*: `https://pavl1k999.github.io` (через запятую можно добавить `http://localhost:8000`);
   - `SESSION_SECRET`, тип *Secret*: любая случайная строка от 32 символов;
   - `STEAM_API_KEY`, тип *Secret*: ключ из шага 1. Можно не задавать: тогда ник и аватар берутся из открытого профиля Steam.
4. **Облачные сохранения** (по желанию): *Storage & Databases* → *KV* → *Create* (`casesim-state`), затем Worker → *Settings* → *Bindings* → *Add* → *KV namespace*, Variable name `STATE`.
5. **Подключите сайт**: в `js/config.js` укажите адрес воркера, например `authApi: 'https://casesim-auth.ВАШ-НИК.workers.dev'`, закоммитьте и отправьте в GitHub.

Через консоль то же самое: `cd worker && npx wrangler deploy`, затем `npx wrangler secret put SESSION_SECRET` и `npx wrangler secret put STEAM_API_KEY` (настройки в `worker/wrangler.toml`). Тесты сервера: `node worker/test.mjs`.

## Запуск

Сборка не нужна — это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` в браузере или выложить папку на GitHub Pages (Settings → Pages → Deploy from branch).

## Картинки без Steam

По умолчанию картинки грузятся со Steam CDN. Если Steam у вас недоступен или нужен полностью автономный сайт, скачайте все картинки (~2100 штук) в папку `img/` один раз:

```bash
python3 scripts/download_images.py
```

Скрипт докачивает только недостающие файлы, его можно запускать повторно. После него сайт берёт картинки из `img/`, а если какой-то нет, пробует Steam. Папку `img/` можно закоммитить, тогда она попадёт и на GitHub Pages. Вернуть загрузку со Steam: `python3 scripts/download_images.py --off`.

## Данные

Скины, кейсы и картинки берутся из открытой базы [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API). Изображения грузятся со Steam CDN. Цены вымышленные и считаются по редкости, оружию, паттерну и износу.

Пересобрать `js/data.js`:

```bash
python3 scripts/build_data.py
```

Состав авторских кейсов, цены и RTP настраиваются в `scripts/build_data.py`. Название сайта задаётся в `App.config` (`js/core.js`).

## Структура

```
index.html            разметка, шапка, лента, меню
css/style.css         все стили
js/data.js            сгенерированная база скинов и кейсов
js/core.js            состояние, цены, звук, модалки, роутер
js/components.js      карточки, рулетка, боты, лента
js/pages/*.js         страницы: главная, кейс, апгрейд, контракты, батлы, профиль, бонусы/FAQ
js/app.js             инициализация, шапка, живая лента
js/art/cases.js       генератор SVG-коробок кейсов и иллюстраций
js/art/icons.js       40 эмблем для коробок
js/fair.js            provably fair (HMAC-SHA256, схема Stake)
js/auth.js            вход через Steam, облачные сохранения
js/config.js          настройки (адрес сервера входа)
worker/               сервер входа через Steam для Cloudflare Workers + тесты
scripts/build_data.py генератор данных (цены, билеты, RTP)
scripts/themes.py     темы и наборы скинов авторских кейсов
tests/fair.test.cjs   тесты provably fair: node tests/fair.test.cjs
```
